Put permanent site photos here (e.g. hero.jpg, cottage-winter.jpg).

Once this site is hosted, you can reference them from the admin panel's
"Vložiť URL obrázka" field using a relative path, e.g.:

    images/cottage-winter.jpg

This is the best way to add photos you want to keep long-term — they ship
with the site, load fast, and don't count against the admin panel's
built-in photo-upload storage limit. See README.md, "Hosting your photos
properly" for the full explanation.
